# Sonveil 1.3.6

Auralis is now **Sonveil**. This release includes the new icon and a more glass-like look while keeping the familiar music screens.

- New adaptive launcher icon built from the supplied Sonveil artwork, with icons for older Android launchers.
- Translucent, edge-lit panels and subtle blue and amber accents.
- Opaque collapsed player, a small gap above the bottom navigation, and a shorter navigation bar.
- The Poweramp Equalizer DVC playback fix from 1.3.5 remains included.

Download `Sonveil-1.3.6.apk` below. Android 8.0 or later is required. It installs over Auralis 1.3.5 without losing app data because the Android app ID and signing certificate are unchanged.

Validation: 63 unit tests passed; Android lint reported 0 errors and 18 warnings; debug and release APKs assembled. The updated layout was reviewed on a Galaxy Z Fold 6.
